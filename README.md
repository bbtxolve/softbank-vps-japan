## 购买前必须知道的几个限制

这部分是很多推荐文不会写、但直接影响使用体验的内容。

**第一，促销款不退款。** 往年周年庆的日本软银/IIJ 特价款在套餐说明里明确标注 "No refund/money back on this plan"。也就是说，数字款和低价年付款买了就不能退，下单前把配置、流量和线路需求确认清楚。常规款的退款政策没有在公开资料中查到统一说法，购买前建议先看 TOS/AUP 条款。

**第二，超售是明面上的事。** digvps 实测直接指出 CPU 超售明显，affyun 的介绍也用了“希望不要超售厉害”的说法。fair-share CPU 的意思是共享核，跑满的场景会被限制。放个人网站、下载机、开发环境没问题，跑持续高负载的数据库、编译任务或 AI 推理就不合适了。

**第三，只支持 Linux。** 全系日本软银套餐系统为 Linux，通过 VirtFusion 面板管理，需要 Windows 的话这个产品线不满足。

**第四，流量是双向计的（Storage 款）。** digvps 收录的 Storage 款流量口径标注为 In+Out，即上传下载都算。实际用量大的人要按双向流量估算，别只看表面的"1TB/月"。

## 常见问题

**GreenCloud 日本软银 VPS 国内访问快吗？**
线路方向上没有硬伤。第三方实测显示三网去程都走软银 bbtec，电信联通直连，移动绕香港，三网延迟都不高。但因为每个地区的路由环境不同，建议下单前用官方测试 IP `103.201.131.131` 实测你本地到东京的延迟和丢包。

**$25/年的套餐为什么经常买不到？**
这是限量补货款，GreenCloud 会分批放出，售罄后要等下一批。2026 年 9 月起社区有补货记录，11 月初监测仍显示有货，但这个状态随时会变。想买这类款只能定期查看库存页面，或者关注店庆活动。

**买错了能退款吗？**
周年庆数字款等促销套餐明确不退款，这一点写在套餐信息里。常规套餐的退款政策建议购买前直接查阅官网 TOS/AUP，不要默认所有套餐都能退。

**超售会影响什么？**
主要影响 CPU 和磁盘 IO 的峰值表现。digvps 实测中 CPU 跑分偏低，说明高负载时会被邻居挤占。日常建站、轻应用感知不明显，但对性能敏感的业务要慎重。
